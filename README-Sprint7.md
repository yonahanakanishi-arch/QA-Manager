# QA-Manager — Sprint 7

## 修正内容

### 未完了カード

最左上の「未完了」を押したとき、`状態 = 完了` の案件を一覧から除外します。

### 案件削除

案件詳細画面に「この案件を削除」ボタンを追加しました。

- 削除前に確認ダイアログを表示します。
- スプレッドシートの行は物理削除せず、`削除フラグ = TRUE` にします。
- 削除案件は通常の一覧・CSV出力から除外されます。
- `QA履歴` に削除記録が残ります。

## 確認手順

1. 「未完了」を押し、完了案件が出ないことを確認します。
2. テスト案件を開き「この案件を削除」を押します。
3. 一覧・CSV出力から当該案件が消え、`QA案件` の削除フラグが `TRUE`、`QA履歴` に削除記録が残ることを確認します。
