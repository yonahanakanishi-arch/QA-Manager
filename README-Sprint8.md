# QA-Manager — Sprint 8（運用強化版）

## 追加機能

### 催促管理

- 「回答待ち」かつ、最終催促日・送付日・受付日のいずれかから7日以上経過した案件を催促対象として表示
- ダッシュボードの「催促対象」からワンクリック抽出
- 詳細画面で催促文を生成・コピー
- 「催促を記録」で最終催促日とQA履歴を更新

### 問い合わせ文生成

詳細画面の「問い合わせ文を生成」から、件名・システム・案件ID・問い合わせ内容を整形してコピーできます。

### 削除済み案件の復元

- 「削除済み案件」で論理削除された案件だけを表示
- 詳細画面の「案件を復元」で通常一覧へ戻せます
- 復元記録はQA履歴に残ります

### ナレッジ検索

「ナレッジ検索: ON」で、ナレッジ対象にチェックした案件だけを絞り込みます。

### 月次集計CSV

対象月を選び、システム・ベンダー単位で受付件数、未完了件数、完了件数、期限超過件数をCSV出力します。

## 動作確認

1. 公開URLに `?action=health` を付けて開き、`"version":"Sprint 8"` を確認します。
2. 回答待ちのテスト案件を作り、送付日を8日以上前にして催促対象へ表示されることを確認します。
3. 詳細画面で「催促を記録」を押し、QA履歴に催促が残ることを確認します。
4. ナレッジ対象にチェックして保存し、ナレッジ検索をONにして表示されることを確認します。
5. テスト案件を削除し、「削除済み案件」から復元できることを確認します。
6. 月を選び、月次集計CSVを出力します。
